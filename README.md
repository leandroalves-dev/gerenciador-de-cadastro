# Meu Projeto

Este projeto é um sistema completo de cadastro de usuários, que permite o gerenciamento de informações pessoais de forma prática e segura.

##Funcionalidades:

Cadastro de usuários com:

- Nome
- E-mail
- Senha (com criptografia via bcryptjs)
- Gênero
- Data de nascimento
- Área de atuação
- Foto de perfil
- Nível de acesso (usuário ou administrador)
- Edição e exclusão de usuários existentes
- Visualização dos dados em tempo real
- Contador de usuários e administradores cadastrados
- Preview da imagem antes do envio
- Armazenamento dos dados localmente via localStorage
